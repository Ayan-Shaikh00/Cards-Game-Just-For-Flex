# 🎮 Emoji Memory Card Game

A fun and interactive **Emoji Memory Card Game** designed to test your memory, concentration, and matching skills! Flip the cards, discover hidden emojis, and find matching pairs using as few attempts as possible.

## ✨ Features

- 🃏 Interactive cards with hidden emojis
- 😀 Multiple emoji pairs to match
- 🧠 Memory-based gameplay
- 🔢 Tracks the number of tries
- 🔄 Reset button to restart the game
- 🌙 Dark-themed user interface
- 📱 Simple and user-friendly design

## 🎯 How to Play

1. Start the game and view the face-down cards.
2. Click on a card to reveal its emoji.
3. Select another card to find its matching pair.
4. Remember the positions of previously revealed emojis.
5. Continue until all matching pairs are found.
6. Try to complete the game in the fewest attempts possible!
7. Click **Reset Game** to start a new round.

## 🛠️ Technologies Used

- **CSS** – Styles the cards, layout, and dark theme.
- **JavaScript** – Handles card flipping, matching logic, and attempt tracking.
